## PDF line-icon system

The small line drawings in the PDF headers are adapted from the original code-built icon system in:

- `/Users/alasdairmaclullich/Library/CloudStorage/OneDrive-UniversityofEdinburgh/@ SOCIAL MEDIA HUB/6_DELIRIUM_SUPPORT_100_MORE_WITH_IMAGES/build_visuals.py`
- Rights record: `IMAGE_SOURCES_AND_RIGHTS.md` in the same folder

That record describes 79 graphics as original project artwork with no third-party photography. The PDF system re-draws only the simple project motifs (attention/head, warning, speech, eye, heart, clock, calendar, home, hospital bed, medicine, walking, document and people) as resolution-independent vectors. It does not copy the social-card wording or use the AI-generated scenes, photographs, memes, screenshots, classical artworks or 4AT artwork.

The motif attached to each sheet is decorative and is not a diagnostic symbol or clinical instruction. Clinical meaning remains in the adjacent text. Every adapted use requires the same final human clinical review as the sheet itself.
